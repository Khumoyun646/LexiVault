# LexiVault Pro — Коммерческий словарь и переводчик (PC + Mobile PWA)

Готовый к запуску и продаже коммерческий веб-продукт (SaaS / PWA) для изучения иностранных языков и ведения личного словаря с автопереводом на русский язык.

## Что уже встроено для продаж:
1. **Модель монетизации (Freemium + PRO-лицензии):**
   - Бесплатный тариф (`FREE`) с лимитом до 30 слов для привлечения пользователей.
   - Тариф `PRO` с активацией по лицензионному ключу (демо-ключи для проверки: `LEXI-PRO-2026`, `VIP-ACCESS-100`, `PRO-UNLIMITED`).
   - Экспорт в **Excel / CSV** (доступен только в PRO-версии) и резервное копирование в JSON.
2. **Устанавливаемое PWA-приложение (Android, iOS, Windows, macOS):**
   - Встроены `manifest.json` и Service Worker (`sw.js`) — пользователи могут установить сайт на рабочий стол телефона или ПК как отдельное приложение.
3. **Онбординг для новых покупателей:**
   - При первом запуске автоматически добавляются 3 стартовых слова (на английском и узбекском), чтобы пользователь сразу увидел, как работает перевод, озвучка и карточки.
4. **Двуязычный интерфейс (RU / EN):**
   - Переключатель языка интерфейса в шапке приложения.
5. **Тройное автосохранение в `localStorage` и алфавитная сортировка:**
   - Основная база + зеркальная резервная копия + автосохранение черновика ввода.

## Запуск проекта локально
```bash
npm install
npm run dev -- --host
```

## Сборка для публикации (Vercel, Netlify, VPS)
```bash
npm run build
```
Готовая папка `dist/` полностью готова к загрузке на любой хостинг. Для настройки своих цен и API скопируйте `.env.example` в `.env`.
